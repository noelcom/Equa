# 0005 – Ingen OCR i v1

Status: accepterad

## Beslut
Inskannade CV:n (PDF utan text) läses inte. De markeras "Kunde inte analyseras" och räknas inte mot kvoten.

## Varför
OCR kräver att bilder hanteras, och bilder kan innehålla porträtt som riskerar anonymiteten. Lokal PDF→Markdown kastar bilder.

## Konsekvenser
Kan övervägas igen om kunder efterfrågar det.
