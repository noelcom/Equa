# 0001 – Stack: Next.js, FastAPI och Supabase (EU)

Status: accepterad

## Beslut
Frontend i Next.js (TypeScript, Tailwind), backend i FastAPI (Python), Supabase (EU) för databas, inloggning och fillagring. Hosting inom EU. Byggplanen (PDF) är en referens, inte ett krav.

## Varför
Ger kontohantering, Row Level Security och krypterad fillagring utan egen kod, och uppfyller GDPR-kravet på EU-lagring.

## Konsekvenser
Att byta någon del kräver en ny ADR.
